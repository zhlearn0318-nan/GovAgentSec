## 身份、权限与审批

| 已实现的范围 | 不能扩大解释为 |
| --- | --- |
| 本机演示 JWT、账号登录 30 分钟、自动会话授权、退出/切换撤销 | 真实组织 SSO、跨全部客户端的统一委托 |
| registry 密级与资源校验；最高账号读取全部登记合成资料 | 任意电脑文件、生产资料库已纳管 |
| 工作区 gov_read_document 使用当前登录身份 | 所有独立 MCP 都继承同一用户身份 |

| admin/weihu 保留原生动作确认并免另一人业务审批 | 关闭全部保护，所有动作均无确认 |

动作确认 60 秒，执行票据 30 秒。待审批与执行回执分区，批准、执行成功、执行失败、拒绝和过期分别表示。原生宿主审批、任务 ACL 记录与工作区确认按真实来源关联；缺少 run 关联的回执不能编造跨 run 父边。旧 U10 手动选材/绑定仍可能作为内部测试接口存在，不是当前用户流程。

## 防护、准入与沙箱

输入和工具结果防护按实际执行模式报告。回复检查启用不代表 observe 已变成强制发送前门控；已发出的流式内容不能宣称可撤回。BLOCK 判定与真正中断需结合 enforced、工具结果、回执确认。

Aegis + Group4 联合准入异常拒绝。静态硬拒绝不运行目标代码；没有代码入口的 Skill 不生成动态执行证明。Group4 行为扫描不等于 Docker 执行。工具声明检查、组件安装准入、服务健康和主体权限分别核验，通过一个不代表其他全部通过。

Docker 是默认会话引擎，srt 可选并有 Windows 冷启动及隔离限制。原生 exec/文件工具进入所选会话后端，MCP 服务、插件和模型 API 不因此都进入容器。Docker 临时输出不等于完成生产办公文件交付；srt 不能宣传为可承受主动隔离攻击的完整边界。详细机制见 [SESSION_SANDBOX_DEMO.md](SESSION_SANDBOX_DEMO.md)。

## 轨迹与本地评审

JSONL 哈希链、锚点和断链检测可发现相应篡改，不抵御同时控制本机链、锚点和运行环境的管理员。图/时间线来自同一记录，页面轮询不是零延迟推送。当前横向图有五类栏目；旧文档的“六栏”不作为验收数量。

未评估显示“尚未评估”；图节点隐藏“token 未提供”说明但没有补数。运行汇总 usage 不均摊成逐次 token。U20 wrapper 默认关闭；启用后也只记录真实回包中可精确关联的用量。

会话可接外部 API，它会收到该会话上下文；**轨迹评审仅本地不等于云会话不出域**。Ollama/启发式/受控 fixture 的来源分别记录。新装默认本地模型，已有本机 DeepSeek 配置保留；本轮文档核对未发送模型请求。

Q 的 E/F/C、S 及缺失规则见 [TRACE_SCORING_AND_EVOLUTION.md](TRACE_SCORING_AND_EVOLUTION.md)。UI 当前 t_star=.75、keep=.9，calibration_version=ui-process-assessment-v1-not-production，calibrated=false、test_only=true。S 严格大于阈值才进入安全集合；实际阻断、缺失或链异常另有隔离。TopK 分母包含安全集合中的 Q 缺失项，但缺 Q 不可入选；数量取 floor，至少两条来源才能生成候选。

生成器 local-common-steps-v1 提取有证据的公共步骤及来源，不是 SkillClaw 全文复现，也不证明通用质量提升或失败恢复已学会。候选在隔离工坊，admission_passed 只是联合检查通过，不等于人工复核/生产发布完成。test_only 不能被管理员身份解除。
