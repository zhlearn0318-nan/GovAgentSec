### 2.3 工具库规则

1. 不在库 → 阻断，文案「不在工具库，已阻断」
2. 在库但身份无权 → 阻断（演示优先）
3. 在库有权但越任务范围 → 审批；批准≠执行
4. 危险族（写/外发/exec）→ 硬策略不放宽

登录→看双库权限摘要→绑会话/选材→聊天任务→闸门→审批→轨迹→适当沙箱动态验证→审计演进评测与候选 skill。
