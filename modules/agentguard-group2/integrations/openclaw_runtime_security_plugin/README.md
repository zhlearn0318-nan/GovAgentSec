# AgentGuard OpenClaw 运行时安全中心插件

这是第二组“面向工具调用和任务执行的安全约束与审批控制技术”的 OpenClaw 原生展示插件。
插件把现有 AgentGuard 执行链路接入 Control UI 侧栏，不创建第二套安全决策逻辑。页面既能读取
真实审计，也能提交受限的演示候选动作，现场运行完整策略控制链。

## 页面内容

- 安全总览：真实受控请求、三态分布、审计字段覆盖和组件健康状态；
- 动作试算：在页面中提交查询、测试付款和危险命令，实时获得三态结果与原始日志；
- 决策审计：按请求展示 `allow`、`require_approval` 和 `deny` 及原因码；
- 审批中心：工作人员可对绑定任务与动作摘要的 `REVIEW` 请求执行批准、拒绝、中断和企业微信提醒；批准后重新验策略、签发一次性凭证并隔离执行；
- 全链路审计：把策略决策、人员身份、审批意见、中断、错误和执行回执关联展示；
- 执行回执：展示一次性票据核销后的隔离执行结果，并可下载证据 JSON；
- 策略与接入：说明第二组边界以及与 Aegis Chain 安装前准入模块的协同接口。

## 责任边界

本插件从“模型候选动作进入策略控制”开始，到“受控工具返回执行回执”结束。它不包含输入攻击
识别，也不提供插件、Skill 或脚本的上传、供应链准入扫描与安装功能；这些属于其他技术方向。

## 本地运行

项目的 `setup_openclaw_agentguard_demo.ps1` 会将本目录加入隔离 OpenClaw 配置并启用插件。
双击项目根目录的 `现场演示-双击打开.cmd` 后，默认浏览器会直接进入本插件页面。

企业微信通知为可选通道。可在插件配置中填写官方机器人 Webhook，或者在启动环境中设置
`AGENTGUARD_WECHAT_WEBHOOK_URL`。插件只接受 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send`
这一官方地址。机器人用于发送待审批提醒；工作人员在 OpenClaw 审批中心完成带身份和意见的
处理。若要直接在企业微信移动端点击审批，需要另行配置企业微信自建应用、OAuth 与回调地址，
不能用普通群机器人 Webhook 冒充交互式审批。

插件页面和接口仅接受本机回环连接；动作提交和审批处理还要求短时页面令牌和同源检查。页面每五秒刷新，
敏感字段和形如 API Key 的值会在服务端序列化前脱敏。
