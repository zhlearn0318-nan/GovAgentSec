# 当前系统基准：比赛电网演示版

核对日期：2026-11-14。本页描述 `demo/competition-grid-20261114` 的源码及已安装演示机配置；本轮回归结果见[验证记录](COMPETITION_VALIDATION.md)。通用 v1.0 的发布包和早期台风演示说明不覆盖本分支差异。

## 版本与入口

- 基于 GovAgentSec v1.0；OpenClaw 固定 **2026.7.1-2**，不修改正式版标签。
- 使用 `Start-GridDemo.cmd`，进入现有 OpenClaw 工作区 `http://127.0.0.1:18789/plugins/govagentsec/welcome`。
- 主导航为 **动态权限、能力准入、演进审计、安全总览、防护设置**。任务在 OpenClaw 原生聊天中执行，顶栏“查看过程”展示本次运行。
- 登录一次自动用于当前浏览器工作区。资料范围由服务端身份和有效授权确定，无需手动绑定任务或勾选材料。
- 首次安装和已有系统迁移见[比赛版说明](COMPETITION_DEMO.md)，启动入口本身不安装基线 Skill。

管理员可以[导入 TXT、Markdown、DOCX](DOCUMENT_IMPORT.md)并指定密级。文件最大256 KB，提取正文最大32 KB。导入资料是用户提供的数据；内置曲线来自匿名样本，档案中的检修及采集事件是合成背景。旧版五份台风资料文件保留为历史测试素材，已不在本分支运行时登记表中。

## 原生工具与运行流程

1. `gov_read_document(document_id)` 经可信身份、登记资源、OPA、任务范围、必要时确认、一次性票据及审计后读取资料。
2. `gov_analyze_grid(period="2024-09")` 再次核验当前身份和两份文件的授权，从受控读取结果计算报告，不接受调用者路径或身份。
3. Skill 正文由宿主加载到本次提示上下文；执行时校验版本与内容摘要。源代码附带基线 **1.0.0**，本机经审核发布的版本独立保存在宿主工作区。
4. 报告显示四条曲线、异常分类、证据和核查建议。链接有效期2小时，网关重启后需在“演进审计 → 当前 Skill 与分析报告”重新打开。
5. 同目标真实轨迹明确关联 `a-park-electricity-diagnosis`，本地评测后筛选候选来源。联合准入通过后仍需管理员审核，只发布到电网演示技能库；新会话加载新版本。

输入防护保留模型判断，并独立记录电网业务的显式外发绕过规则。规则命中不能表述为全部防护模型均命中。D004 密级拒绝及 D005 受保护资源拒绝沿用原机制，不能通过普通批准绕过。

## 页面与审计

| 入口 | 当前用途 |
| --- | --- |
| 动态权限 | 登录、资料读取与申请、文件审批、待确认与执行回执 |
| 能力准入 | Skill/MCP 扫描、联合准入报告、人工复核 |

| 防护设置 | 沙箱、演示身份源等维护配置 |

调用图分为 **LLM、Skill、MCP / 工具、结果、防护 / 审批** 五栏。未评测显示“尚未评估”；工具预检失败与正常完成分开显示。重复成功读取会计入冗余，失败恢复和变化后的重新读取另行处理。

本机此前按授权清理过旧业务历史，Aegis 使用检查点核验保留后缀，并在页面标注“历史前缀已清理”。这不代表未经清理的完整历史链。分支包含核验代码和合成测试，不包含本机审计数据库或清理清单。

## 配置与证据边界

电网配置将主 Agent 技能限制为 `grid-anomaly-diagnosis`，工具限制为 `gov_read_document` 和 `gov_analyze_grid`。外部会话模型和凭据沿用安装者配置；轨迹评测仍为本地。Docker 是默认会话隔离后端，srt 为可选项。

仓库保存源码、匿名样本、基线 Skill 和回归测试。本机已发布 Skill、对话、报告、授权、轨迹、密钥和模型权重不随 Git 复制，因此克隆分支不等于复制当前录屏现场。操作顺序见[电网脚本](../modules/grid-demo/README.md)，文件差异见[比赛版说明](COMPETITION_DEMO.md)。
