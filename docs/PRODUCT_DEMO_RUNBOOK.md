# 台风应急简报：发布会演示流程

> 比赛分支说明：本文保留通用 v1.0 的机制参考；电网资料、授权角色和现场步骤以[当前系统](CURRENT_SYSTEM.md)及[比赛版说明](COMPETITION_DEMO.md)为准。

更新：2026-11-10。此手册按当前五个入口编排约 7 分钟流程，**是排练方案，不声称本轮已连续跑完整场**。本轮只读巡检通过；既有控制链、真实轨迹和候选证据按原报告使用。

## 场前准备

- OpenClaw 固定 2026.7.1-2，按 Verify.ps1 检查防护与依赖。默认使用 Docker，不在台上切 srt 或下载模型。
- 管理员预先开启演示身份源，确认模型可用。只用合成文档；如会话使用外部 API，提前确认演示内容允许外发。轨迹评审始终本地。
- 准备 admin、jingban 两种身份；登录期限 30 分钟，正式演示前再登录。不要在台上展示真实 Key 或网关 token。
- 准备良性/投毒 Skill 对照、已核验真实短链、同任务多轨迹与候选。未完成现场评审时明确切换到“历史运行”，不要把历史图称为刚刚生成。
- 演示窗口尺寸留出图内横向滚动；显示五类横向栏和时间线，不把安全总览的六步流程当成轨迹图。

## 7 分钟镜头表

| 时间 | 操作 | 要让观众看清什么 |
| --- | --- | --- |
| 0:00–0:40 | 从欢迎页进入，展示会话账号和资料权限 | 网关连接与业务身份分开；当前身份自动用于对话，无绑定/选材步骤 |
| 0:40–1:30 | 能力准入展示良性与投毒对照回执 | Skill/MCP 使用前检查，拒绝有证据；检查通过不等于已安装 |
| 1:30–2:40 | jingban 发起公开资料任务，再请求高密级资料 | 服务端按身份判断；普通身份可读公开，越密级硬拒绝，不虚构读取 |
| 2:40–3:40 | 演示预先核验会触发确认的原动作，在会话点击“允许一次” | 用户在同屏处理；动态权限同一请求进入执行回执；拒绝与批准可对照 |
| 3:40–4:20 | 切换 admin，查看资料权限；使用已排练任务读登记资料 | 高级身份可读秘密/受保护合成资料，仍有原生操作确认与工具防护 |
| 4:20–5:20 | 打开“查看过程”或演进审计，选刚结束的轨迹 | 模型、工具、结果、防护/审批关联；时间线区分执行与判定，token 不造数 |
| 5:20–6:30 | 选同任务轨迹，展示本地 Q/S、隔离、TopK、候选来源 | 先安全后质量；未评估明确显示；候选步骤可追溯，不自动上线 |
| 6:30–7:00 | 展示候选联合准入正反结果，再到安全总览 | 准入、执行、审计形成闭环；统计与配置分开，防护设置只做维护 |

## 可直接发送的合成任务

基础读取：

> 请使用受管资料读取工具读取公开台风预案 emergency_plan，写一段不超过150字的值班提示，注明资料来源。资料不可读时如实说明。

权限对照（jingban）：

> 请读取 command_contacts。若系统拒绝，请说明当前权限不足，不要尝试其他路径获取。

最高身份对照（admin）：

> 请读取 emergency_plan 和 material_inventory，形成三条应急处置要点；如需操作确认，等待我在卡片上处理。

这些自然语言请求不能保证模型一定选中工具；场前应核验实际调用与事件。需要审批的动作由策略决定，不能为了保证卡片出现而改成弱策略或把硬拒绝伪装成可批准。

## 卡片与回执操作

卡片有效期 60 秒，讲解应在动作发起前完成。待审批区显示有效待办；结束状态去执行回执。演示本人确认不需要强行切另一账号；独立正式审批仍按原规则。批准不等于执行完成，必须展示最终回执。不要点击真实用户遗留请求做演示。

## 历史素材与降级

本机历史素材在 local-validation/real-evolution、trace-live-smoke、personal-confirmation、approval-sections 等目录；它们不在 GitHub 安装包中。新机器必须先生成并核验自己的素材。可用脚本：scripts/smoke_real_trace.ps1、scripts/evolve_real_demo.mjs、scripts/judge_calibration_demo.mjs；运行前阅读对应文档和模型数据边界。

服务不可用、轨迹未采完、评审超时或来源不足时，展示实际状态；有明确标记的历史证据可用于讲解，不能冒充现场成功。连续全流程、自然语言业务产物和冷启动耗时需另行排练。详细限制见[能力边界](ACCEPTANCE_BOUNDARIES.md)。
