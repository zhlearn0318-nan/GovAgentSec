## 4. 现场失败如何处理

| 现象 | 处理 |
|---|---|
| 未连接网关 | 停留连接页，由管理员确认；不露出/朗读令牌，不称业务登录成功 |
| 身份过期 | 就地重新登录，服务端重新核对任务；不扩大权限 |
| 审批过期 | 对未消费授权点“重新申请原动作”，核对新请求并重新审批；旧授权作废。不延长TTL、不重放旧票据，已消费动作不再申请同一旧凭证 |
| 安全服务不可用 | 展示本次未执行；切到标明历史时间的备录，不把不可用说成检测到攻击 |
| 工具报错或模型未按预期调用 | 展示真实失败与回执；不改提示反复试到“看起来成功”而隐藏前次记录 |
| 图有缺失/断链或连接中断 | 展示异常和最后更新时间；断链排除演进，不补假节点。页面不可见或历史包不会持续轮询，不把停留画面当实时流 |
| 本地评分慢/不可用 | 使用预评历史结果并标来源；回退启发式必须标注，不伪造Ollama评分 |
| 候选复核按钮禁用 | 核对来源：test_only本身禁止生产复核；非test_only还需可信管理员。停在候选状态，不切身份强开门禁 |
