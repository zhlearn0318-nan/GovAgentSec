# Aegis 服务与准入界面

此目录包含扫描后端、准入策略、工具和 OpenClaw 页面。用户从政安智枢“能力准入”进入，不需要另开独立演示站点。

- backend：扫描、证据、规则、MCP 配置检查和安装策略。
- openclaw_plugin/aegis-admission-ui：工作区嵌入页面。
- config：扫描器与隔离执行配置。
- tools、demo_samples：程序工具与明确标注的合成回归材料。

部署使用仓库根目录 Setup-Windows.ps1；接口见 [API_V1_CONTRACT.md](docs/API_V1_CONTRACT.md)，使用逻辑见 [产品手册](../../../docs/产品使用逻辑与模块协同.md)。本目录不发布阶段计划、实验结果报告或开发提示词。
