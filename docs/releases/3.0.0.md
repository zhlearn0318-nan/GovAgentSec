## 发布范围与已知限制

只推送源码、合成夹具、锁定依赖清单、配置模板、设计和使用文档。`local-validation/`、真实轨迹 JSONL、截图素材、模型权重、虚拟环境、运行日志、数据库、用户配置和真实凭据留在本机。文档中的 `local-validation/...` 链接指开发机证据，GitHub 源码分支不包含这些文件；可按对应文档本地复跑。

演示身份源不等于生产组织 OIDC；候选联合准入通过不等于已安装或发布。U20 wrapper 默认关闭，Ollama 评审不经过它；启停与恢复见 [模块说明](../../modules/govagentsec-usage-wrapper/README.md)。重复 span、无 usage 或采集故障均诚实显示缺失，不均摊或估算 token。

Windows 上的 SRT/Docker 覆盖范围与依赖见 [会话隔离说明](../SESSION_SANDBOX_DEMO.md)。已知原生读取延迟、输入护栏误报和演示边界见 [近期总交付说明](../POST_U11_DELIVERY_REPORT.md)。3.0 不声明已完成生产 OIDC 接入、论文阈值复现或所有生产交付验收。
