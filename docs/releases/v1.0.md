# 政安智枢 GovAgentSec 正式版 v1.0

发布日期：2026-11-10。宿主固定 **OpenClaw 2026.7.1-2**。

本次建立正式发行序列：集成版本为 **1.0.0**，Git 标签为 **v1.0**。早期 3.0 是开发阶段编号；已有历史标签 v1.0.0 保留不移动，组件内部版本独立维护。

## 本版内容

- 统一工作区：动态权限、能力准入、演进审计、安全总览、防护设置；运行指标与防护状态从设置独立出来。
- 当前业务身份自动用于会话，受管资料按身份授权；会话内确认卡片、动态权限审批和执行回执分开呈现。
- Skill/MCP 准入、输入与工具结果防护、受管动作策略/一次性票据、Docker/srt 会话隔离。
- 横向分栏调用图与时间线、本地质量/安全评估、同类轨迹归纳候选 Skill 及联合准入。尚未评估显示明确状态，候选准入通过不等于生产发布。
- Windows 完整安装入口：固定宿主、依赖与模型下载、配置备份、真实检查、桌面启动、机器可读安装报告。
- 外部 API 接口保留，新增 `Configure-Model.cmd` 向导入口；新装可先用本地 Ollama，现有模型配置保留。

## 下载与使用

在本发布页下载 **GovAgentSec-v1.0-windows-x64.zip**，用 **SHA256SUMS.txt** 核对后解压，双击 **Setup-Windows.cmd**。也可下载并检查 **Bootstrap-Windows.ps1** 后运行，它会自动下载校验并调用同一安装器。

## 使用条件

完整防护链需要 NVIDIA CUDA 与 Docker Linux 引擎；首次系统授权、WSL 初始化或重启可能需要用户操作。发行包只含提交过的源码和必要资源，不含真实密钥、轨迹、模型权重或本机运行数据。演示身份不是生产 OIDC；本地评审阈值不是论文阈值复现。已有固定宿主适配层随安装备份部署。

已验证安装计划、新配置 schema、配置保留、ZIP 安全检查、官方 npm 宿主的适配安装/恢复和相关回归；**尚未完成全新 Windows 机器整套依赖下载到推理成功的端到端验收**。能力边界见仓库独立文档，不以“正式版”替代生产安全认证。
