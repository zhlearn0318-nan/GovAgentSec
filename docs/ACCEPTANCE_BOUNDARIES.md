# 能力与验收边界

2026-11-09更新，依据11月8日评审及本轮U24实现、隔离验证。本文件面向评委、交付与维护人员；不应整段搬进业务前端。[JUDGE_USER_FULL_CRITIQUE](JUDGE_USER_FULL_CRITIQUE.md)保留当时的问题快照，当前状态以本文件和本轮证据为准。

## 1. 可支持的结论

GovAgentSec已经在固定OpenClaw 2026.7.1-2上验证选定输入攻击停止、受控工具/原生任务权限、一次性授权、轨迹完整性与候选准入。真实采集链与合成测试均有，必须逐份说明来源。

本轮真实宿主隔离控制链通过，使用本地确定性模型及合成材料；它证明安全执行链，**不证明通用模型理解能力、办公产物质量或正式组织部署完成**。另外已实际运行本地 Ollama 的选材到简报任务，业务完成失败：页面任务契约未安全传递至独立 MCP 服务，下游 `P006_PARAMETER_SOURCE_UNTRUSTED` 将两次文档读取转审批。25事件真实链有效，公告成功，文档未执行。报告见 `local-validation/u24-task-materials/2026-11-08T16-53-50-145Z/live/report.json`。这不是“尚未测试”，也不能以主机任务门放行冒充下游业务完成。

U24已接入欢迎页、当前任务材料选择、审批到期重新申请、可自动更新的过程图、本地评审作业和历史包浏览。主导航为“任务／能力库／待审批／审计与改进”。`/plugins/govagentsec/welcome`提供连接引导，网关认证后进入业务登录；它不替代宿主认证，也不为未登录访客开放业务数据。功能实现、隔离测试与完整发布会排练是不同证据，不能互相替代。

## 3. 身份、审批与文件

现有演示身份源激活约15分钟，业务JWT最长5分钟；原生任务审批授权60秒、票据30秒。刷新页内委托丢失；身份过期/撤销必须重新登录核验。审批讲解在批准前完成，批准后立即重试，不通过延长TTL改善演示。到期或消费动作保留墓碑；未消费的过期授权可点“重新申请原动作”，由服务端重新核验并创建新请求，旧授权失效。已消费凭证不能重放；硬拒绝不能转成可批准动作。

原生聊天入口的业务身份检查与MCP适配器自身身份检查是两道检查。审计应区分发起人和执行服务身份，不能混成组织统一委托。候选复核要求宿主可信设备管理员，普通业务演示身份不能确认；本轮过程评估生成的test_only候选即使由管理员操作也不能提交生产复核。

材料卡只提供服务端登记且当前主体可选的材料。确认后生成任务范围；“本次任务指令”供复制到对话，确认材料不会自动发起模型请求。新增材料需重新确认或走允许扩展的审批，执行中不能修改范围。

受控读文件使用登记的隔离合成文档；工具只接受document_id，不能覆盖路径/主体/密级/凭证。D004/D005是硬拒绝；A004及任务可扩展范围审批均不能绕过硬拒绝。业务文件接入、组织目录和正式权限分配需另行落地。

U23审批事件来自私有worker审计投影，覆盖本项目原生task ACL流程；原请求、批准在原run，执行在重试run并明确关联。缺失关联显示回执，不制造跨run父边，不回填旧历史。

过程视图在页面可见时轮询，结束后继续观察120秒以接收晚到审批事件；历史包不轮询，长时间未结束的记录停止快速跟随并提示核验。断连保留上次记录和时间，不能把旧画面当新事件。关键过程合并有精确起止关联的模型/工具事件，完整事件与时间线仍可展开；采集异常只折叠展示，不删除证据。

## 4. 隔离与数据处理

安装前Aegis沙箱、Group4扫描、会话Docker/srt、AgentGuard MCP授权分别承担不同职责。会话Docker的工作区只读、临时输出和工具依赖约束尚不支持“任意Word办公任务都能交付”的说法。srt在Windows下有启动与通路边界，详见[会话沙箱文档](SESSION_SANDBOX_DEMO.md)。

轨迹评审仅Ollama/启发式/受控fixture，本轮没有外部模型请求。默认轨迹正文hash/摘要，不上传原prompt、参数或输出。**本地安全评审不等于聊天模型也在本地**：现网会话可配置外部API，业务输入是否出域必须按当前会话实际配置告知用户。

U20默认关闭；固定宿主未提供的逐次usage不补造、不从总量均摊。字段缺失用未采集，不用0。实际启用wrapper另走配置备份与明确验证。

## 5. Q/S与候选

Q保持现有E/F/C公式和缺失规则；N须与可观测工具起止对一致。S严格大于t_star才进入安全集合，强制阻断或证据不足隔离。本地标定版本包含not-production，不能把论文0.55阈值当本地已验证标准。

界面仅允许Ollama或启发式；endpoint、模型路由、阈值与标定配置由服务端决定。当前固定t_star=.75、`ui-process-assessment-v1-not-production`、calibrated=false、test_only=true。Ollama失败回退需记录实际评审来源；网关重启遗留作业标为interrupted，不静默续跑。

TopK分母为所选同任务、已确认、安全通过集合，**包含其中缺失Q者**；数量为floor(分母×keep)，仅有可计算Q者可被选中。keep=.9、2安全→目标1，不能满足候选至少2来源要求。界面预览显示分母、目标及最终来源，来源不足禁用生成。生成绑定所选轨迹和评分的快照，证据变化必须重新预览；不会悄悄扩大到任务全集。

历史六条真实轨迹结果：4正常S=1/Q=.95；D004轨迹隔离；参数修正恢复轨迹因缺工具起始事件隔离；最终选3，有2公共工具步骤。恢复轨迹未入选，不能说已学习失败恢复。H使用未标定先验，.95不代表业务结果准确率。业务质量提升需要留出任务、前后同条件对比、结果量规另证。

该真实批次保留在独立`local-validation/real-evolution/2026-11-07-multi-trace-final`，可在“审计与改进”的“记录来源”中选择“台风应急简报 · 6条历史真实运行 · 历史只读”。同一视图查看评分、候选并点击步骤来源返回包内轨迹；不复制进现网，不重新评估或生成，不接受任意目录导入。当前工作区与历史数据分开展示，历史截图不得当本轮现网生成。admission_passed仅检查通过，不自动安装；test_only候选不能因准入通过或管理员身份解除限制。

## 6. 文案应放在哪里

| 内容 | 产品中如何呈现 | 文档中保留什么 |
|---|---|---|
| 演示/组织身份 | 一处“演示身份（非生产）”；无组织源时不假登录 | 签发器、JWKS、受众、角色映射、OIDC接入runbook |
| 已阻断/观察/不可用 | 当前动作的真实结果与下一步 | hook覆盖、错误矩阵、停止断言 |
| 任务/密级拒绝 | 哪份材料、为何拒绝、能否申请 | 原因码、策略映射、边界条件 |
| 准入/安装/发布 | 检查通过、尚未安装、待复核分别表示 | combined策略、哈希、测试loader边界 |
| 数据与评分来源 | 合成材料/历史记录、本地过程评分、缺证据 | 标定版本、论文差距、H依据、fixture来源 |
| 沙箱 | 当前引擎/准备状态；选择srt时耗时提醒 | Windows Alpha、WFP/allowRead机制、完整探针 |
| 审计 | 完整性异常、最后更新时间、影响当前任务的缺失 | JSONL/锚点算法、未覆盖审批、字段来源 |
| 工程验收 | 不展示Uxx、PASS/FAIL表和长篇“边界说明” | 命令、版本、测试数量、已知限制、证据路径 |

清理工程话术不等于删除“证据不足”“候选未安装”“服务不可用”等事实；这些会改变用户是否可以继续操作。

## 7. 本轮结论与待验证项

当前可演示：欢迎与业务登录、已登记材料选择、选定真实阻断、任务拒绝零读、双人一次性授权、过期动作重新申请、自动更新的过程图/时间线、本地过程评审、历史包内多轨迹筛选与候选来源。需继续验证：本地通用模型完整业务产物、连续两轮发布会流程、服务持续性和更广材料/工具覆盖。不可据此验收：组织SSO、生产文件权限、全部工具统一身份、普遍低误报、业务质量提升、自动发布。

U23曾出现网关与sidecar意外退出，根因未定；本轮短链通过不等于消除此风险。文案和演示不能把健康探针200当长时间可靠性证明。
