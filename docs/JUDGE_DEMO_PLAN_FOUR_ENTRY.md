## 1 一句话定位

台风应急简报故事：经办在值班任务里查预案、理物资、准备通知；安全系统在需要时介入；每个决定可追溯；同类经验形成候选但不自动安装。

**权威源 = 资料库 + 工具库**（服务端登记，页面只提交 ID；聊天与页面前置闸门消费同一目录）。

| 四模块 | 产品映射（四入口） | 评委听到的一句 |
| --- | --- | --- |
| 风险识别 | 行为护栏（防护回执 / 注入停止） | 危险输入进不了任务 |
| 行为约束 | 权限闸门（动态权限 + 审批） | 身份不够硬拒；任务不够可批一次 |
| 组件准入 | 能力准入（工具库 / Skill·MCP） | 有问题的组件接不进来 |
| 评测审计 | 过程台账 + 经验自演进（审计演进） | 谁批了什么对得上；候选≠安装 |

## 4 双库故事一句话流程图

```
欢迎页 → 动态权限登录(jingban)
      → 资料库三级×三账号摘要（公开可办 / 内部·机密·秘密越密级硬拒）
      → 工具库（可用 / 无权 / 准入失败 → 阻断，零执行）
      → 绑定会话 + 选公开材料 → 回聊天短任务
      → 闸门：注入停止 · 越密级硬拒 · 越任务申请
      → shenpi 批一次 → 重试成功 → 再请求拒绝
      → 能力准入：良性 ALLOW / 投毒 BLOCK（未安装）
      → 审计演进：六轨迹筛选 → 候选步骤可溯源 → 联合准入通过仍不装
      → 防护设置：总览 → 实际防护状态 → 配置与维护（仅 OpenClaw+沙箱）
```

资料矩阵口播一句：「经办只能公开；主管可读内部；管理员看全部登记合成资料——越密级不能靠审批抬高 clearance。」

## 5 轨 A · 8 分钟时间表

| 时间 | 操作 | 台词 | 证据 | 禁止话术 |
| --- | --- | --- | --- | --- |
| 0:00–0:40 | welcome → 动态权限；`jingban` 登录；看双库摘要与当前身份行 | 「先确定谁办、资料库和工具库各自允许什么。」 | 顶栏身份=经办；资料库三级摘要；工具库可用/无权清单 | 「已经登录网关就等于业务登录完成」；手动下拉换人 |
| 0:40–1:20 | 绑定当前会话；选**公开**材料；回聊天发短任务（或展示已核验公开短链） | 「公开材料放行；范围来自服务端，不是页面自己算的。」 | 任务绑定确认；公开材料可读回执或历史短链（须标历史） | 把历史短链说成「刚才现场读出来的」 |
| 1:20–2:00 | 展示**注入停止**回执（现场或历史 live-input-block，须标注） | 「合成攻击输入在进任务前被阻断，回执确认停止，工具阶段未继续。」 | stopConfirmed / CRITICAL；工具 0 | 只有 BLOCK 标签、没有停止回执 |

| 4:10–5:00 | 能力准入：良性回执 ALLOW、投毒 BLOCK；工具库同源 | 「可用能力先检查；有问题的组件不能接入；人工复核≠安装。」 | 回执类型齐全；未安装 | 「准入通过就是已上线」 |
| 5:00–6:20 | 审计演进：六轨迹表 → 隔离 → TopK → 两步候选 → 查看来源 | 「先隔离危险和证据不足，再比过程质量；每步能追溯。」 | 4 安全 / 隔离项；keep 分母；候选来源 hash | 把候选说成已发布 Skill |
| 6:20–7:20 | 防护设置：安全总览 → **实际防护状态**（演示身份绿、回复检查已启用）→ **配置与维护**仅 OpenClaw+沙箱 | 「状态卡来自真实本地快照；配置区只动宿主与沙箱，不在这里改准入规则。」 | 三块顺序；绿标签不可伪造离线为绿 | 把观察模式说成已改后台能力 |
| 7:20–8:00 | 停在候选/设置；口述**三条边界**收束 | 「①演示身份不是组织 OIDC；②轨迹与评审不出域；③候选准入≠安装发布。」 | 讲稿固定三条 | 「生产就绪」「自动发布」「OIDC 已接通」 |

## 7 四入口走位图

```
welcome
  └─ 动态权限（permissions）     ← 唯一登录 · 双库摘要 · 任务绑定/选材 · 审批队列
  └─ 能力准入（admission）       ← 工具库 · Skill/MCP · 报告 · 复核 · 规则
  └─ 审计演进（audit）           ← 六栏调用图 · 时间线 · 对比 · 本地评测 · 候选
```

兼容：旧 `home/login/approvals` → permissions；`compare` → audit 子页；`skills` → admission 子页。聊天仍是执行入口；范围管理在动态权限。

## 9 失败话术

| 场景 | 台上说法 | 动作 |
| --- | --- | --- |
| 登录/委托过期 | 「演示委托有短 TTL，我重新登录，权限仍以服务端为准。」 | 回动态权限重登，不切账号伪装 |
| 审批窗未就绪 | 「批准必须另一人；我们切到已登录的审批上下文。」 | 不自批 |
| 聊天无完整业务产物 | 「完整自然任务仍有衔接缺口；这里展示的是已核验控制链/历史切片。」 | 切标注正确的证据包 |
| 注入/阻断页空白 | 「主镜头改用带 stopConfirmed 的历史实机回执。」 | 打开 U15 行为护栏包 |
| 候选按钮禁用 | 「现网确认在身份未就绪时保持禁用——这正是门禁，不是故障。」 | 展示 gate-disabled |
| 评委问是否生产就绪 | 「三条边界：非组织 OIDC；轨迹不出域；候选≠安装。」 | 停在边界页，不承诺排期 |
